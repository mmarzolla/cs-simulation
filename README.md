# Simulation course, MSc in Computer Science, University of Bologna, Italy

This repository contains some teaching material for course [37760 -
Systems
Simulation](https://www.unibo.it/en/study/course-units-transferable-skills-moocs/course-unit-catalogue/course-unit/2026/518514),
MSc in Computer Science, University of Bologna, Academic Year
2026/2027. Here you will find some demo programs related to the
following topics:

- Markov Chains
- Queueing theory
- Discrete-Event Simulation

The provided programs require the following software packages:

- [Java Modeling Tools (JMT)](https://java-modelling-tools.github.io/).
- [NetLogo](https://www.netlogo.org/).
- Any Java JDK, such as [OpenJDK](https://openjdk.org/index.html).
- [Jupyter notebooks](https://jupyter.org/).

Additional teaching material, including lectures slides, are available
on the [instructor's personal Web
site](https://www.moreno.marzolla.name/teaching/simulazione/2026-2027/).
